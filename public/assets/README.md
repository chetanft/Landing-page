# Assets Directory

This directory contains image assets for the application.

## Current Files

- `google-icon.svg` - Google sign-in button icon (placeholder - needs to be replaced with actual export from Figma)
- `microsoft-logo.svg` - Microsoft sign-in button logo (placeholder - needs to be replaced with actual export from Figma)  
- `product-showcase.svg` - Product showcase image for carousel (placeholder - needs to be replaced with PNG export from Figma)

## To Replace Placeholders

1. Open the Figma design: https://www.figma.com/design/UrgiE4l2RIBbZi5XO6kwBV/Log-In?node-id=1-25256
2. Select each image element in Figma
3. Export as:
   - Google icon: SVG format → save as `google-icon.svg`
   - Microsoft logo: SVG format → save as `microsoft-logo.svg`
   - Product showcase: PNG format → save as `product-showcase.png` (then update LoginPage.tsx to use .png instead of .svg)
4. Replace the placeholder files in this directory
5. Restart the dev server
